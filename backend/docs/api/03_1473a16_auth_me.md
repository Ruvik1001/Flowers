# Current user profile

Short description: Return authenticated staff profile, roles, permissions and object scopes.

## Endpoint description

Requires Bearer access token. Used by frontend to bootstrap session and authorization UI.

## Endpoint name

`GET /api/v1/identity/auth/me`

## Accepted headers

| Header | Required | Description |
|---|---|---|
| `Authorization` | yes | `Bearer <access_token>` |
| `X-Request-Id` | no | Correlation id |

## Accepted fields / params

None.

## Accepted body

None.

## Request example

```http
GET /api/v1/identity/auth/me HTTP/1.1
Host: localhost:8080
Authorization: Bearer <access_token>
```

## Response example

```json
{
  "id": "uuid",
  "email": "admin@flowers.local",
  "is_admin": true,
  "roles": ["admin"],
  "permissions": ["*"],
  "object_scopes": {"*": ["*"]}
}
```

## Error codes and messages

| HTTP | code | message |
|---|---|---|
| 401 | `missing_token` | Bearer access token required |
| 401 | `invalid_token` | Token is invalid or expired |
| 404 | `user_not_found` | User not found |
| 502 | `upstream_unavailable` | identity service unavailable |
